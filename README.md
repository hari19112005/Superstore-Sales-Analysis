
# Superstore Sales Analysis | Power BI

## Project Overview
Developed an interactive Power BI dashboard to analyze Superstore sales, profitability, regional performance, and customer segments. The project focuses on transforming business data into meaningful insights to support data-driven decision-making.

## Objectives
- Analyze overall sales and profit performance.
- Evaluate regional and product category performance.
- Identify top-performing customers.
- Analyze customer segment contributions.
- Track monthly and yearly sales trends.
- Support business decisions through data visualization.

## Tools & Technologies
- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query
- Microsoft Excel
- Data Modeling

## Dataset Description

The project consists of three tables:

| Table | Description |
|---|---|
| Orders | Order details, sales, profit, quantity and dates |
| Customers | Customer details, region and segment |
| Products | Product categories and subcategories |

## Project Implementation

### 1. Data Preparation
- Imported Orders, Customers and Products datasets.
- Prepared data for analysis.

### 2. Data Modeling
- Created relationships between fact and dimension tables.
- Developed a Calendar Table for time-based analysis.
- Implemented a structured data model.

### 3. DAX Measures
- Total Sales
- Total Profit
- Profit Margin
- Previous Month Sales
- Sales Growth Percentage
- Total Orders

### 4. Dashboard Development
Developed an interactive executive dashboard featuring:

- KPI Cards: Total Sales, Total Profit, Profit Margin, Growth % and Total Orders.
- Line Chart: Yearly Sales Trend with Forecast.
- Column Chart: Sales by Region.
- Bar Chart: Profit by Category.
- Table: Top 10 Customers.
- Donut Chart: Customer Segment Distribution.

### 5. Interactive Filters
- Year
- Month
- Region
- Category

## Business Analysis
The dashboard helps answer the following business questions:

- Is the business growing month over month and year over year?
- Which region is underperforming?
- Which category has the highest growth?
- Which customer segment contributes the most revenue?
- What strategic actions can improve business performance?
